== Jekyll

https://jekyllrb.com/docs/
Jekyll is a static site generator. It takes text written in your favorite
markup language and uses layouts to create a static website. You can tweak
the site's look and feel, URLs, the data displayed on the page, and more.

Notes:

== Bootstrap

https://getbootstrap.com/docs/5.0/getting-started/introduction/
Get started with Bootstrap, the world's most popular framework for
building responsive, mobile-first sites, with jsDelivr and a
template starter page.

Notes:
  o  Moncle3 gh-pages appears to use Bootstrap SASS version 3 (old)
  o  the file monocle3/node_modules/bootstrap-sass/package.json includes
       "name": "bootstrap-sass",
       "version": "3.3.7",
  o  the file monocle3/node_modules/bootstrap-sass/CHANGELOG.md includes
       Framework version: Bootstrap **v3.3.6**

  o  the following is based on my rudimentary understanding of
     bootstrap
       o  the Monocle3 documentation web site uses a Bootstrap 'grid'
       o  the web site uses the small grid tier
       o  the grid can rearrange the blocks depending on the size of
          the display: the small grid tier does something when the
          display is less than 576 pixels wide
          see: https://getbootstrap.com/docs/5.0/layout/grid/  'grid options'

  o  we had a web site problem in which the navbar table of contents (toc)
     moved from the left side to beneath the body text (overlapped by
     the body text). Jeremy Stone provided a solution consisting of
     modifying

     css/main.scss
       edit the block starting with @media to

@media (min-width: 576px) {
  .sticky-navigation {
    position: sticky;
    top: 0;
  }
}

      and replace each docs/*.html line that begins with
      '<div class= "col-sm-4' (near the top to of the file)
      look like 

<div class= "container">
  <div class= "row">
    <div class= "col-sm-4 sticky-navigation">        <-- this line!!!
